# Módulo organization

## Papel
O módulo `organization` representa a entidade central do sistema do ponto de vista organizacional.

## Responsabilidade principal
Definir a organização como fronteira lógica de dados e tenant da aplicação.

## Papel no sistema
A organização é a base de associação para:
- usuários;
- fazendas;
- custos;
- fretes;
- ajustes comerciais;
- cálculos econômicos.

## Observação
A organização não é apenas uma entidade cadastral. Ela define o limite lógico de isolamento entre empresas.
