# Documentação local do core-service

Esta pasta reúne a documentação local dos módulos do `core-service`.

Seu papel é complementar a documentação macro da raiz do projeto, oferecendo contexto mais próximo da implementação atual de cada módulo.

## Relação com a documentação da raiz

A documentação em `docs/` na raiz do repositório concentra:

- visão do produto;
- roadmap;
- arquitetura geral;
- etapas;
- specs;
- plans;
- decisions;
- templates;
- tasks.

Já esta pasta concentra documentação de contexto local do núcleo implementado.

## Arquivos desta pasta

- `module-overview.md`
- `organization.md`
- `identity.md`
- `farm.md`
- `market.md`
- `cost.md`
- `pricing.md`

## Objetivo

Esses arquivos existem para registrar, de forma curta e útil:

- a responsabilidade de cada módulo;
- seus conceitos principais;
- seus limites atuais;
- suas dependências mais importantes.

## Regra prática

Atualizar esta pasta quando houver mudanças relevantes em:

- responsabilidade do módulo;
- conceitos centrais;
- dependências principais;
- limites do escopo atual;
- relação entre módulos.
