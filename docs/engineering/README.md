# Documentação de engenharia

Esta pasta reúne materiais mais formais, consolidados ou apresentáveis do projeto AgroBasis.

Seu conteúdo pode incluir:
- documentos de engenharia do sistema;
- visões gerais em PDF;
- materiais preparados para apresentação a cliente, banca, professor, parceiro ou stakeholder externo;
- snapshots documentais mais completos de uma determinada fase do projeto.

## Papel desta pasta

Os arquivos desta pasta têm caráter mais expositivo e consolidado.

Eles são úteis para:
- comunicação externa;
- apresentação do projeto;
- registro de uma visão mais ampla e integrada do sistema;
- distribuição de material em formato fechado ou estável.

## Relação com a documentação viva

A documentação desta pasta não deve ser tratada como a fonte viva principal do desenvolvimento.

A manutenção contínua do conhecimento do projeto deve ocorrer prioritariamente nos arquivos markdown organizados nas demais pastas de `docs/`, especialmente em:
- `00-product/`
- `01-architecture/`
- `02-stages/`
- `03-specs/`
- `04-plans/`
- `05-decisions/`

Sempre que necessário, documentos desta pasta podem ser atualizados ou regenerados a partir dessa documentação viva.

## Regra prática

- `docs/engineering/` = documentação consolidada e apresentável
- restante de `docs/` = documentação operacional e evolutiva do projeto
