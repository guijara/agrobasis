# Etapa C

## Nome
Primeira camada analítica do pricing.

## Objetivo
Evoluir o sistema do cálculo determinístico atual para uma leitura analítica mais orientada à composição, interpretação e leitura do pricing.

## Estado atual
A Etapa C foi iniciada com a C.1, dedicada à análise atual do pricing.

## Direção da etapa
Esta etapa busca permitir que o sistema responda não apenas:
- qual é o valor atual?

mas também:
- como esse valor é composto?
- qual é o impacto de cada componente?
- o que esse resultado representa economicamente?

## Observação
A camada de inteligência especializada e probabilística não pertence a esta etapa. Ela fica reservada para a etapa posterior de simulação e cenários.
